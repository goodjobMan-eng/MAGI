## 데이터 없이 태블릿에서 쓰기
1. 와이파이에서 태블릿 크롬으로 사이트를 연다.
2. 첫 화면의 **데이터 없이 쓰도록 이 기기에 저장**을 누르고 100%가 될 때까지 기다린다(약 75MB).
3. 크롬 메뉴 → **홈 화면에 추가**(또는 앱 설치)로 바탕화면 아이콘을 만든다.
4. 현장에서는 데이터·와이파이 없이 아이콘으로 연다. GPS·카메라는 데이터 없이도 동작한다.
- 이야기나 그림을 고친 뒤에는 `python3 tools/build_offline.py` 를 실행해 목록을 다시 만들고, 태블릿에서 다시 저장한다.
